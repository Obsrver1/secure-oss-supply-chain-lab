# Secure OSS Supply Chain and GitHub Guardrails Lab

A hands-on security engineering lab focused on protecting open-source software supply chains and GitHub-based development workflows.

## Planned Capabilities

- GitHub branch protection and repository rulesets
- Secure GitHub Actions workflows
- Dependency and license policy enforcement
- Python-based repository security auditing
- SBOM generation and validation
- Artifact provenance and integrity checks
- Terraform-managed security controls
- GitHub OIDC integration with AWS
- Security testing against intentionally vulnerable repository configurations
